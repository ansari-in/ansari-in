# Featured Projects

## Iri-Shield — Node.js API Security

> A practical API security package built while working on API Security research.

**Iri-Shield** provides security middleware and utilities for Node.js applications.

### Highlights

* SQL Injection detection
* XSS detection
* SSTI detection
* NoSQL Injection detection
* Behavioural anomaly detection
* Multi-step attack sequence detection
* Explainable risk scoring
* Client identity continuity & drift detection
* Automatic rate limiting & IP blocking
* API Key & JWT authentication utilities
* Automatic PII & secret redaction
* SQLite / MongoDB / Memory storage
* Built-in benchmarking & security evaluation
* Real-time admin dashboard
* Configurable security rules

**Built with:** Node.js • Express.js • JavaScript • MongoDB • SQLite • API Security
